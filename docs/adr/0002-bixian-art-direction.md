# 笔仙采用旧黄纸、朱砂字与局部烛光

对应 issue #9。美术以克制的民俗灵异为基调：旧黄纸、朱砂字、乌木短笔、左上方暖烛光；不引入惊吓图像。新文案「灯花未落，纸上已有回音」只作氛围叙述，问审与回答器仍遵循 ADR-0001。

## 选型与边界

- 纸面使用原创 SVG 纤维、折痕、边缘污渍纹理；无需位图背景，缩放不失真。CSS 光照与左侧烛台保持同一方向。纹理只作背景，不参与扶笔坐标映射。
- 正式笔为 SVG 乌木杆、金属箍、朱线与尖笔锋。保持 `gradientUnits="userSpaceOnUse"`，笔长 16u；尖端与投影中心均为局部 `(0,0)`。不修改 100×160 纸面、答案字位和漂移引擎。
- 纸面所有答案字、标题和固定题字使用本地 Ma Shan Zheng 子集字体（23 KB，OFL）。正文、口诀和任意用户问题采用站点正文排版，不再依赖系统楷体。字体来源及授权见 THIRD_PARTY.md。
- 大厅保留浅色 neo-brutalism；笔仙入口卡采用暗色底、朱砂印、暖纸按钮，沿用大厅卡片边框和硬投影。游戏样式限定于 `bx-*`，不修改 body、导航或全站主题；离场即卸载暗色场景。
- 次要「扶笔与扰动」选项收进可键盘访问的原生 details，纸面始终完整显示；手机采用单列。
- `prefers-reduced-motion: reduce` 关闭岛内所有 CSS 动画，包括烛焰、纸面烛光、落定字与提示呼吸；沿用已有无震动、无摇晃、无脉冲逻辑及短暗反馈。
