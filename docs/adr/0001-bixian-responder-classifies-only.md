# 笔仙回答器只分类、不生成文本

笔仙游戏中用户得到的每一个答案都来自预设模板（答案类别的具体字值）；Jev 模型只通过 system-one 的 choice 问题裁决「问审（可答/越界）」与「落定何字」，从不生成任何文本。原因：system-one API 只支持 choice/score/noul 三类问题，本就没有自由文本生成；且预设模板让答案可控、可测、可离线兜底（仙力竭尽退随机），不受延迟与每日配额的进一步挤占。

## Considered Options

- 让 Jev 生成灵异风格的自由文本答案——被否：API 不支持；即便支持，生成不可控、更慢、更耗配额，与「预设分类回答器」的产品定位相悖。
